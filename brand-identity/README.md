  * **السطر الثاني (أبيض):** `تملك شقة العمر بسعر خيالي  •  واتساب: 0934222900`

  * كبسولة ذهبية علوية: `العرض رقم [XX]  •  تملك شقة العمر بسعر خيالي`

### ج) بطاقة شرح الغرف المتزامنة (Dynamic Room Description Card)
* **الموقع:** الثلث السفلي الآمن (`X: 34..686`, `Y: 910..1035`).

  * **السطر الأول (أبيض عريض `34pt`):** اسم القسم الحالي (مثلاً: `المطبخ الأميركي المفتوح`).
  * **السطر الثاني (ذهبي `22pt`):** الميزة التسويقية للقسم (مثلاً: `مطبخ عصري أنيق مطل على الصالون وعلى بلكونين`).
